# Portfolio résumé

- Final download: `public/documents/Urwah-Siddiqui-Resume.pdf`.
- Editable layout/text snapshot: `resume/Urwah-Siddiqui-Resume.html`.
- Canonical public content: `lib/professional.json` (also used by the website).
- Generator: `scripts/build-resume.mjs`. Regeneration overwrites the HTML snapshot and PDF; edit the JSON for content and the generator for persistent layout changes.

Generate locally from the repository root on Windows with Chrome and Arial installed:

```powershell
npm.cmd install --prefix .local-tools --no-audit --no-fund --package-lock=false playwright-core
node scripts/build-resume.mjs
```

`CHROME_PATH` may override the Chrome executable. The HTML references local Windows Arial files, which Chromium embeds into the PDF; these system font files are not distributed in this repository. For another operating system, update the generator's font paths and browser path before regenerating. The site continues using its existing bundled fonts.

The final PDF is one A4 page, single column, with 10.5pt body text, embedded Arial regular/bold, selectable text, conventional headings, explicit bullets and three contact hyperlinks. Automatic hyphenation is disabled. Reinspect the rendered PDF and extracted text after any edit; page fit is not automatic validation and no ATS score is claimed.
